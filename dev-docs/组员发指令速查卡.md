# 组员给 AI Agent 发指令速查卡（零经验版）

> **先说一个关键认知**：你的 AI Agent **不会自己分配任务**，也不会凭空想任务。
> 你每个人要做什么，已经写在 `MEMBER_<你的字母>_DEV_GUIDE.md` 里了。
> 你唯一要做的，就是：**认领字母 → 把 3 份文档喂给 AI → 从自己那本指南里抄一个具体任务发过去**。
> Agent 是"执行者"，不是"出题人"。它照文档写代码，你照纪律验收。

---

## 第 1 步：认领你的字母

| 字母 | 你是谁 | 做什么 |
| :--- | :--- | :--- |
| **成员 A** | 组长 / 后端 + RAG 核心 | 工程骨架、向量库、SSE 流式答疑、知识点生成 |
| **成员 B** | 后端业务 + 数据库 | 建表 DDL、登录鉴权、课程/课件/问答 CRUD、接口文档 |
| **成员 C** | 前端（学生端） | 学生问答界面、打字机流式、出处抽屉、Markdown 渲染 |
| **成员 D** | 前端（教师端）+ 答辩 | 教师后台、课件管理、问答记录查看、答辩材料 |

不确定自己是哪个？看 `TEAM_WORK_DIVISION.md` 第一章。

---

## 第 2 步：把 3 份文档拖进 AI 对话（只做一次）

在你的 AI 编程工具（Claude Code / Cursor / 等）里，**新建项目后的第一条消息**就照下面发。
把文档文件拖进对话框（Claude Code 用 `@文件名` 引用）：

- `AGENT_INSTRUCTIONS.md`
- `DEV_SPECIFICATION.md`
- `MEMBER_<你的字母>_DEV_GUIDE.md`
- `COLLAB_AGENT_PROTOCOL.md`（**协作流程**：开工移卡片、每日站会发 Issue、提 PR 的自动动作，Agent 会照着执行）

（`THREE_WEEK_PLAN.md` 排期也一并打开，方便对照每周任务。）

> **本周任务已拆成 GitHub Issue 并指派到人**（看板见群公告链接）。开工前让 Agent 跑 `gh issue list --assignee @me --state open` 认领自己的任务——**Issue 里的"验收标准"就是你要做到的程度**，不要凭感觉。

---

## 第 4 步：之后每个任务，都这么发

完成上一条后，**不要一次让 AI 写完整模块**。从你自己的 `MEMBER_<字母>_DEV_GUIDE.md` 里挑下一章，照同样的格式发：

```text
我现在的任务是：<从 MEMBER_X_DEV_GUIDE.md 第 X 章抄一个具体小节，例如"实现 4.3 课件上传接口">。
先列文件清单让我确认，再写代码。写完后跑 <mvn clean compile / npx vue-tsc --noEmit 再 npm run build>，贴出成功输出。
```

---

## 三条保命纪律（每条消息背后都要遵守）

1. **第 1~2 天只做技术验证（成员 A 跑 Chroma + 大模型连通），不写业务代码。** 底层不通，上面写得越多浪费越多。
2. **AI 说"完成了"不算数，命令跑过才算数。** 后端看 `BUILD SUCCESS`，前端看两条命令无红色报错。报错就贴给 AI 修，连修 3 次不行就发群里问组长。
3. **AI 提"要不要顺便加个功能"，一律回"不需要，只做文档里写的"。** 多加的功能会和别人代码打架。

> 完整纪律与铁律见 `README.md` 第二节、第三节。
